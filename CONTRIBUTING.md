# Contributing

1. Create a focused branch from `main`.
2. Keep credentials, personal data, generated build output, and local
   deployment files out of commits.
3. Run the relevant Maven, worker, and web checks before opening a pull
   request.
4. Update `CHANGELOG.md` for user-visible, security, operational, or workflow
   changes.

Pull requests should explain the problem, the design choice, and how the
change was verified.
